# EQuest

Personal project. A 3D client and server demo that runs a custom game of EverQuest. The client is only compatible with the custom server and not EverQuest's actual network. Written in C# and uses MonoGame for 3D rendering. EverQuest assets belonging to Daybreak Game Company are not provided.

- EQuestClient: The game client.
- EQuestLib: Library for code shared by the client and the server.
- EQuestRender: 3D rendering library.
- EQuestServer: The game server.
- S3DFileLib: Library for reading EverQuest's S3D and WLD data files.
